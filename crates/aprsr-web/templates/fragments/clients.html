Nothing here stores state in the DOM that must survive that: the search term, the sort and the set of expanded rows all live in the controller and are re-applied after each swap, keyed on the registry id. With JavaScript off the search box and the sort buttons are not rendered at all — see the `data-table-controls` block — and the table below is a perfectly good static table. -#}
